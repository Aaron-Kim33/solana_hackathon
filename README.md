# Lumber Rush

Seeker-first mobile tapping game prototype built with React Native and Expo.

## Current playable loop

1. Tap the ancient tree to deal damage.
2. Fatigue rises and reduces axe power at high levels.
3. When the tree falls, logs spawn around the forest.
4. Drag each log away to collect it. Chopping remains locked until every log is collected.
5. Use Rest to lower fatigue.

## Run locally

```bash
npm run android
```

Use an Android emulator or device. The initial gameplay prototype has no wallet dependency; the next milestone adds Solana Mobile Wallet Adapter and devnet profile authentication.
