1. **소스 동결 및 릴리스**: 보안·랭킹 포함 커밋 확인. 기존 Railway 볼륨·계정 보존.
   서버 배포/새 EAS Preview 요청은 승인 후 실행. 불필요한 이미지/DB/키 업로드 금지.
2. **최종 APK 확인**: 기존 Preview에 업데이트 설치. 일반 서버 계정의 두 순위 버튼/내 순위,
   보관함·트롤리·강화·보상·음향·재실행 확인. admin은 제외되는 것이 정상.
   빈 순위·느린 네트워크·실패 후 새로고침도 확인. 추가 APK 권한 병합/기존 서명 일치 점검.
3. **지속 가능한 APK 링크**: 최종 파일을 GitHub Release 같은 공개 다운로드 위치에 올린다.
   정확한 소스 커밋·EAS ID·APK SHA-256/서명/패키지를 기록. 만료되는 이전 EAS 링크만 제출하지 않음.
4. **덱 확정**: 새 릴리스/폰 확인 뒤 초안의 `Final APK and phone QA are still pending` 등 현재 상태를 업데이트.
   PDF를 Drive에 업로드하고 비로그인 보기/다운로드 확인. PPTX는 수정용이며 직접 제출 형식으로 사용하지 않음.
5. **실제 3분 영상**: `demo-script-2026-10-05.md`에 맞춰 폰 녹화. 진행 계정/다른 시점 컷 표시.
   실제 없는 Mainnet 성공·다른 유저·리텐션 지표를 만들지 않음.
6. **양식 입력**: `submission-fields-2026-10-05.md` 영문 초안 사용. 투자 여부·개발 날짜·이전 수상은 사용자가 사실 확인.
   제목/해당 모바일 개발 질문/SKR 답변/덱·영상·저장소·APK URL 입력 후 우선 SAVE.
