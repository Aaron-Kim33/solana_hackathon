# 한국어·영어 및 첫 수확 검증

## 서버 미로그인 첫 화면 — 외부 APK 확인 필요

- `server-preview`에서 로그인 전 상단이 로컬 연습/서버 미연결로 표시되고, 하단에 연습 진행이 서버로 옮겨지지 않는다는 안내가 계속 보여야 합니다.
- 로그인 전 지갑 버튼은 목재 20개 전에도 **서버 저장 연결**을 열어야 합니다. 로컬 지갑 완료 플래그만 바꾸거나 로컬 목재를 서버에 올리면 안 됩니다.
- 서버 로그인 후에는 서버 저장/랭킹 미반영으로 바뀌고, 별도 서버 계정의 목재·레벨이 보여야 합니다. 로그인 전 연습 저장은 로그아웃 시 그대로 돌아와야 합니다.
- 플레이 가이드가 로컬 연습/서버 저장을 구분하고, 서버에서 아직 연결되지 않은 보석·특성을 사용 가능하다고 설명하지 않는지 한국어·영어로 확인합니다.
- 이 항목은 코드·자동 검사만 진행했으며 외부 APK/실기기 화면 검증 전까지 완료로 표시하지 않습니다.

개발 빌드 기본 언어는 한국어, release 빌드는 영어입니다. 메뉴에서 즉시 전환할 수 있습니다.
언어, 목재, 경험치, 강화, 피로도 회복 기준 시각, 퀘스트 이력과 공개 거래 영수증은 기기에 저장됩니다.
지갑 세션은 재연결이 필요합니다. 기존 v1 디스크 저장은 목재·경험치·강화·피로도·퀘스트를 유지하며 v2로 변환됩니다. 나무 HP는 남은 비율을 유지합니다.

## 게임

- 신규 로컬 저장/신규 서버 계정에서 첫 목재 회수 전에는 하단에 드래그 안내가 보입니다. 첫 회수 후에는 `첫 수확 1/20`이 보이고 누르면 퀘스트 패널이 열려야 합니다. 보유 목재를 소비해도 이 누적 진행도는 줄지 않아야 합니다.
- 누적 회수 19→20에서 하단 안내가 지갑 퀘스트로 바뀌고, 로컬/서버 각각 한 번만 완료 안내가 떠야 합니다. 서버에서는 요청이 확정되기 전 이 안내가 먼저 뜨거나 로컬 재화가 지급되면 안 됩니다.
- 서버 미로그인 로컬 연습에는 이 퀘스트 단축 안내를 표시하지 않습니다. 한국어/영어, 좁은 화면에서 2줄 이내로 읽히고 나무/드랍 조작 영역을 가리지 않는지 확인합니다.

- 캐릭터 첫 화면: 중앙 캐릭터, 오른쪽 도끼 슬롯, XP 및 핵심 능력치만 표시됩니다. 도끼 슬롯/장착 카드 → 도끼 상세 → 장비 변경에서 보유 도끼만 표시되는지 확인합니다.
- 변경 후보 선택은 미리보기일 뿐 저장하지 않습니다. '장착'을 눌러야 실제 변경됩니다. 기념 도끼 최초 장착 전 +1, 해금 이후 외형 간 변경은 '변화 없음'입니다.
- 도끼 상세의 슬롯을 누르면 해당 슬롯 옵션만 관리합니다. 같은 종류도 2개 보유하면 양쪽에 장착할 수 있고, 1개뿐이면 다른 슬롯에서 비활성화됩니다. 보유 수량과 공격력 증감 및 변경 후 치명타 수치를 확인합니다.
- 각 상세 화면의 뒤로 버튼과 닫기, 다시 캐릭터 진입 시 첫 화면 복귀를 확인합니다. 스크롤이 다른 패널에 이어지지 않아야 합니다.
- 목재 0.7배 내림/데미지 확률/레벨당 성장 공식은 화면에서 숨기고, 현재 능력치와 수확 보너스는 유지합니다. 실제 계산 로직과 저장 데이터는 변경하지 않습니다.
- 게임 화면을 위아래로 드래그해도 화면 전체가 스크롤되지 않아야 합니다.
- 왼쪽 위 메뉴 → 퀘스트/캐릭터를 열고, 패널 안에서만 스크롤되는지 확인합니다.
- 캐릭터 화면에는 외형, 장착 도끼, 강화 비용, 경험치, 스킬 해금 상태가 표시됩니다.
- 내구도 0에서 나무의 업그레이드 표시가 나타납니다. 이를 눌러 보유량·비용·다음 등급 보상을 확인합니다.
- 부족한 목재로는 업그레이드 버튼이 흐리게 비활성화됩니다. 무료 같은 등급 재벌목은 언제든 가능합니다.
- 충분한 목재로 업그레이드하면 비용이 한 번 차감되고, 다음 등급의 나무가 최대 내구도로 나타납니다.
- 나무가 쓰러진 상태에서도 기존 드랍은 5초 규칙을 따릅니다. 패널을 열어도 드랍 시간이 멈추지 않습니다.

- 한국어/English를 전환하여 상태, 버튼, 현재 안내 메시지가 함께 바뀌는지 확인합니다.
- 나무를 반복 탭하면 매번 피해 숫자가 나무 옆에서 올라갑니다. 일반 피해 1에서는 드랍이 없고 2에서는 목재 1개, 3에서는 2개입니다. 치명타 숫자는 금색 별표로 표시됩니다.
- 떨어진 목재를 5초 안에 12픽셀 이상 드래그한 뒤 놓으면 수량이 한 번만 증가합니다.
- 목재를 두 개 이상 떨어뜨리고 각각 생성 시점으로부터 5초 후 사라지는지 확인합니다.
- 목재를 누른 채 다른 손가락으로 나무를 탭하면 피해가 발생하지 않아야 합니다.
- 목재를 잡은 상태로 만료되어도 다음 나무 탭은 정상 동작해야 합니다.
- 메뉴 → 퀘스트에서 첫 수확 카드에 접근합니다. 게임 화면은 스크롤되지 않습니다.

## Devnet

### 첫 기록 보상 및 다음 퀘스트

- 잔액 0인 Devnet 지갑으로 기록 요청 시 지갑 서명을 열기 전에 'Devnet 테스트 SOL 부족' 안내가 팝업과 퀘스트에 표시됩니다. 이미 전송된 거래는 자동 재전송하지 않습니다.
- 무료 테스트 SOL을 받은 후에는 예상 수수료와 잔액을 다시 검사합니다. 수수료 조회 실패 시 전송하지 않습니다.
- 성공·미확정·실패 결과가 퀘스트 창 뒤에 숨지 않고 팝업과 기록 카드에 표시되는지 확인합니다.
- 테스트: `node --experimental-strip-types --test --test-isolation=none src/game/progression.test.mjs src/solana/record-errors.test.mjs`
- Devnet 기록이 미확정/실패 상태면 보상 수령이 잠겨 있어야 합니다. 확정 후 '첫 기록 보상 수령'이 활성화됩니다.
- 보상 수령: 기념 스킨만 해금되고 실제 피해는 변하지 않습니다. 안내에서 캐릭터 화면으로 이동할 수 있습니다.
- 기념 스킨 최초 장착: 보라색/민트색 도끼로 바뀌며 영구 데미지 +1 해금 안내가 나타납니다. 옵션 2개는 유지됩니다.
- 최초 장착 직후 다음 퀘스트는 목재 0/100입니다. 장착 전 수집분은 계산하지 않습니다. 회수한 목재(추가 수확 포함)만 누적됩니다.
- 첫 기록의 도끼는 장착 공격력 +2가 별도로 있습니다. 기본 도끼로 바꾸면 장착 보너스만 사라지고 영구 +1은 유지됩니다. 강화/재시작/재장착으로 영구 보너스가 중복 증가하지 않습니다.
- 99개에서 진행 중, 100개에서 완료이며 표시 수량은 100으로 고정됩니다. 목재를 강화에 소비해도 진행도가 줄지 않습니다.
- v1/v2에서 이미 기록이 확정된 경우 재전송 없이 보상 수령이 가능합니다. 기념 보상은 로컬 게임 보상이며 NFT 발급이나 실제 토큰 전송은 없습니다.
- 기기 저장 삭제/변조에 대한 서버 차원의 중복 방지는 아직 없습니다. 실제 지갑 서명·Devnet 확정의 종단 테스트는 사용자 승인이 필요합니다.

## 성장 및 휴식

- 게임 화면 및 나무 강화 패널에 현재 레벨의 '10% 확률로 목재 +L'이 표시되고, 패널에 다음 레벨의 보너스가 표시됩니다.
- 기본 목재가 나오는 타격에 풍성한 수확이 발동하면 안내와 금색 별표 묶음이 표시됩니다. 묶음 숫자는 기본+추가 총량입니다. 막타에서는 벌목 완료 안내가 우선하며 묶음은 금색으로 표시됩니다.
- 추가 수확도 드랍 시점에는 재화/XP가 증가하지 않습니다. 5초 안에 회수할 때만 총량을 한 번 지급하고, 놓치면 모두 사라집니다.
- 기본 목재 0 타격에서 추가 수확은 절대 발생하지 않습니다. 치명타와 수확 보너스는 동시에 발동할 수 있으며 추가 목재 자체에 치명타 배율을 곱하지 않습니다.
- 누적 수확 19개까지 지갑 연결이 잠겨 있고 20개부터 열리는지 확인합니다.
- 도끼 강화에 목재를 써 잔액이 20 미만이어도 연결 해금이 유지되어야 합니다.
- 도끼 레벨 1→2는 20개, 나무 레벨 1→2는 30개가 필요합니다. 잔액 부족/최고 레벨에서 지출이 없어야 합니다.
- 캐릭터 경험치는 회수 시에만 증가합니다. 30 XP에서 레벨 2가 되고 피로도가 0으로 초기화됩니다. 게임 화면 XP 바도 함께 갱신됩니다.
- 회복/레벨업 없이 타격하면 피로도가 정확히 1씩 증가하고 100회째에 100%가 됩니다. 100%에서도 이미 떨어진 목재를 회수할 수 있습니다.
- 도끼 Lv.1/2의 일반 피해는 1–3/2–4입니다. 타격 속도나 피로도에 따라 피해가 추가/감소하지 않습니다.
- 나무 HP는 Lv.1/2/3에서 300/400/500입니다. 나무 레벨로 목재 보상이 배수 증가하지 않습니다.
- 캐릭터 패널 → 테스트 옵션 3종 · 각 2개까지 받기 → 같은 종류를 두 슬롯에 장착합니다. 피해 +4 / 치명타 확률 +4%p / 치명타 피해 +20%p 중 해당 합계가 적용됩니다. 다른 종류 조합도 가능합니다. 지급을 반복해도 수량이 무한 증가하지 않습니다.
- 도끼 강화/앱 재시작 후 옵션을 유지하며, 장착 해제하면 표시된 피해/치명타 수치가 원복됩니다. 테스트 지급 버튼은 release에서 숨겨집니다.
- 자동 테스트에서 만렙 도끼 200·캐릭터 200·나무 1000 상한, 치명타 21.9%/304%, 외형 Lv.50→51 경계와 저장 변환을 확인합니다.
- 나무 Lv.1000을 베면 엔딩 안내가 뜨고 무료 같은 등급 재벌목은 계속 가능합니다.
- 피로도는 30분 전까지 그대로, 경계 시점에서 20% 감소해야 합니다. 150분이면 100%→0%입니다.
- 테스트용 휴식 버튼은 개발 빌드에서 28%를 즉시 회복합니다. 배포 빌드에서는 보이지 않습니다.
- 앱 재시작 후 상태가 유지되고, 앱을 꺼둔 시간의 자연 회복이 적용되어야 합니다.
- 자동 테스트: `node --experimental-strip-types --test --test-isolation=none src/game/progression.test.mjs`
- 성장 진단: `node --experimental-strip-types src/game/simulate-balance.mjs` (기기 저장 변경 없음)

공식 테스트 지갑 소스: https://github.com/solana-mobile/mock-mwa-wallet

테스트 지갑에서 Authenticate를 실행한 뒤 게임으로 돌아와 연결합니다.
인증에 기기 PIN/생체 인증 설정이 필요할 수 있습니다. 실제 자금을 사용하지 않습니다.

- 연결 거절/호환 지갑 없음: 선택한 언어로 오류 안내가 표시됩니다.
- 20개 회수 전에는 기록 버튼이 비활성화됩니다.
- 지갑 연결·도끼 Lv.2·캐릭터 Lv.2·나무 Lv.2 이후 마지막 기록 퀘스트가 열립니다.
- 기록 버튼을 누르면 테스트 SOL 수수료 및 공개 기록 안내가 표시됩니다.
- 취소하면 거래 요청을 보내지 않습니다.
- 진행하면 지갑이 서명 승인을 요청합니다. 게임은 개인키를 취급하지 않습니다.
- 서명자는 연결한 주소와 일치해야 하며 거래는 devnet Memo 한 개만 포함합니다.
- 제출 후 확정되면 성공 메시지, 확정 확인 실패 시 미확정 메시지와 Explorer 링크가 표시됩니다.
- 실패/지연 거래를 성공으로 표시하거나 자동 재전송하지 않습니다.

이 기능은 첫 수확의 기념 기록입니다. 조작 방지 점수 검증이나 영구적인 업적 발급은 아직 구현하지 않았습니다.
# 보석 / 성장 퀘스트 추가 검증

- 캐릭터 → 캐릭터 특성: 3종 현재/다음 효과와 목재 비용을 한국어/영어로 확인합니다. 목재 부족/만렙은 비활성화되며, 강화 후 목재만 줄고 코인/XP는 그대로여야 합니다. 도끼 교체 후에도 특성이 유지되어야 합니다.
