## 9/30 공동 숲 1차 — 로컬 코드만 완료

- 사용자 승인에 따라 광산·묘목길 공동 콘텐츠의 첫 단위를 구현했다. 서버가 벌목/목재 묶음 확보/트롤리 출발의 일일·주간 진행을 기록하고, 퀘스트 자재를 계정당 1회 지급하며 두 시설에 기여한 양을 공유한다. 하루 최대 15, 한 주 최대 150 자재다.
- 시설은 매주 월요일 UTC 00:00에 새로 시작한다. 각 레벨 기준은 지난주 퀘스트 자재를 수령한 고유 계정 수 × 10/25/50/80이며, 지난주 참여가 없으면 1인 기준이다. 이는 운영 데이터가 없는 초기 가설이지 검증된 밸런스가 아니다.
- 지갑 연결 서버 화면의 메뉴에 한/영 공동 숲 패널을 추가했다. 현재 시설 레벨은 표시 단계일 뿐 채굴/묘목 보상, 개인 기여 단계 보상, 펫 파견은 아직 없다. 이런 효과를 이미 얻는다고 안내하지 않는다.
- 기존 저장을 초기화하지 않는 SQLite v6 마이그레이션과 중복 요청/실패 롤백 검사를 추가했다. 자동 검사 191개, 타입 검사, Android JS 번들 export가 통과했다. Railway 배포, 새 APK, 실제 지갑·다중 기기 QA는 미완료다. 이 기능을 제출판의 작동하는 공동 경험으로 소개하기 전에 서버 배포와 두 계정 이상으로 기여 반영을 확인해야 한다.

### 9/30 공동 숲 밸런스·지도 후속 수정

- 1명이 주간 자재를 광산에 몰아 Lv.4를 만든 실사용 피드백을 반영했다. Lv.2/3/4/5는 각각 최소 1/2/3/5명의 서로 다른 기여자와 자재 20/45/80/120 × 지난주 참여 기준을 모두 요구한다. 시설당 누적 10자재 이상 기여한 계정만 인원에 포함한다. 이는 지갑 다계정 방지책은 아니다. 기존 기여는 지우지 않고 새 기준으로 레벨만 다시 계산한다. 수치는 실사용 참여 규모를 보기 전까지 시험값이다.
- 보석 아래 지도 버튼에서 개인 숲/공동 숲을 선택하고, 공동 숲은 별도의 전체 화면으로 들어가도록 바꿨다. 햄버거 메뉴 항목은 제거했다. 지도는 오프라인에서도 열지만 공동 숲 입장은 서버 저장 연결 상태에서만 가능하다.
- 이 수정은 로컬 코드이며 Railway 및 Preview APK에는 아직 반영되지 않았다. 자동 검사 193개, 타입 검사, Android JS 번들 export는 통과했다. 서버 재시작·Metro 새로고침 후 개발 앱에서 확인하고, 실제 여러 계정의 공동 레벨 QA를 해야 한다.

### 9/30 공동 숲 그림 장면

- 사용자가 텍스트 목록이 아닌 별도의 공간을 요청해 지도 뒤 공동 숲을 그림 기반 장면으로 바꿨다. 광산 입구와 묘목길이 있는 새 세로 배경 `assets/community/community-clearing-v1.png`를 생성했고, 해당 시설 그림의 터치 영역을 누르면 서버 기여량·인원 조건과 기여 버튼이 아래 시트에 열린다. 자재 퀘스트도 장면 안의 별도 버튼/시트로 옮겼다.
- 기존 숲 그림은 생성 이미지의 스타일 참고 자료로만 사용했다. 실제 장면은 앱 자산에 저장한다. 첫 Android 화면 검사에서 `cover`가 주요 시설을 잘라내는 문제를 찾아 전체 이미지가 보이도록 수정했고, 에뮬레이터에서 광산/묘목길 장면·광산 기여 시트·퀘스트 시트 배치를 확인했다. 서버 재화의 실제 기여 버튼은 누르지 않아 자재/저장 데이터는 바꾸지 않았다.
- 이 변경은 로컬 개발 앱에서만 보이며 Railway/Preview APK에는 미배포다. 레벨별 시설 외형 변화, 펫 파견, 채굴/묘목 보상은 아직 미구현이다.

### 9/30 피로도·공동 자재 퀘스트 조정

- 피로도 100% 도달 순간과 100%에서 다시 나무를 홀드할 때 한/영 안내를 표시하고, 피로도 상태 줄에도 벌목 중단과 다음 20% 회복까지 남은 시간을 계속 보인다. 목재 회수는 기존대로 허용한다. 재시도 홀드 중 알림이 매 타격 주기로 반복되지 않도록 시작 단계에서 한 번만 알린다.

## 승인된 제품 방향

핵심: 계속 때릴지, 5초 후 사라질 목재를 회수할지 선택하는 모바일 성장 게임.

1. 기존 게임을 보존하면서 메인 입력을 서버 검증 경로에 연결. 타격 시각 피드백은 즉시, 재화는 서버 확정 후.
2. 첫 5분 UX/아트, 한손 조작, 한국어/영어, 실제 신규 사용자 피드백 우선.
3. 확정형 외형 상품 하나의 구매→검증→한 번 지급→복구→착용 흐름. 실제 결제 활성화는 별도 승인과 검증 필요.
4. SGT 전용 외형/배지 또는 공정 도전은 여력이 있을 때. SGT는 mint 기준 중복 방지, 인간/매크로 방지의 완전한 증명이 아님.
5. 일반 성장과 보상 경쟁은 분리. 유료 공격력/자동줍기/피로도 회복이 보상 경쟁의 점수·참가권을 늘리지 않게 함.
6. 제출판에서 유료 랜덤 보석, 자동 에어드랍, 대규모 신규 콘텐츠는 후순위. 무료 재화 뽑기도 확률 공개.
