# 코인 / 타격 XP 경제 v3 (저장 v5)

2026-09-13 구현. 아래 수치는 플레이테스트용이며 실제 결제·거래·현금화와 무관합니다.

## 규칙

- 도끼 강화는 코인 20 × 현재 도끼 레벨을 소비합니다. 실패 확률 없음.
- 고목 강화는 기존 목재 30 × 현재 고목 레벨을 소비합니다. 내구도 0일 때만 가능.
- 매 고목 처치(같은 단계 반복 포함)는 코인 40 × 고목 레벨을 확정 지급합니다.
- 유효 타격마다 독립적인 5% 확률로 ceil(고목 레벨 / 10) 코인을 추가 지급합니다. 목재가 0개인 타격도 대상. 코인은 자동 획득하며 별도 드래그 없음.
- 타격 XP = 고목 레벨. 피해·치명타·목재 회수량에 영향받지 않습니다. 실제 타격이 거절되면 XP/코인도 없음.
- 새 고목 레벨 진입 XP = 새 고목 레벨 × 10. 같은 단계 재성장은 추가 XP 없음.
- 목재 회수는 목재/누적 수확만 증가시키고 XP/피로도를 변경하지 않습니다.
- 레벨업 피로도 초기화는 타격/고목 강화에서 발생합니다. 첫 피로도 100% 이전에 레벨업하면 벌목을 더 할 수 있습니다.
- XP 곡선 누적 기준점: 캐릭터 1=0, 2=50, 5=4,000, 20=420,000, 100=22,000,000, 200=140,000,000. 기준점 사이에는 (레벨−1)에 대한 로그 보간을 사용합니다. 내부 공식은 유저 UI에 표시하지 않습니다.

## 성장 검증

`node --experimental-strip-types src/game/simulate-economy.mjs`

신규 저장, 도끼 강화 즉시/고목 소진 후 강화, 장비 옵션·첫 기록의 도끼 없음, 목재 100% 회수. 시드 1/42/2026/100/999. 피로도 100% 시 즉시 휴식하는 합성 시뮬레이션이며 자연 회복/실제 달력 시간은 모사하지 않습니다.

고목 1,000 처치까지 212,195–212,549회. 피로도 레벨업 초기화를 포함하는 소진 구간은 2,020–2,024회이며 달력 일수가 아닙니다. 도끼는 고목 약 142 부근에서 만렙에 도달하는 경향이 있어 도끼 성장 기간도 후속 조정 대상입니다.

시드42의 목재 80% 회수 조건에서는 자금 부족에 의한 반복 고목 없이 같은 결과였습니다. 전설 확률/치명타 피해 옵션을 처음부터 지급한 스트레스 조건에서는 고목100/500/1000의 캐릭터가 19/89/179였습니다. 강한 장비는 같은 단계까지 필요한 타격과 XP 획득 횟수를 함께 줄이므로 캐릭터 만렙을 고목1,000에 항상 보장하지 않습니다. 반복 벌목으로 XP를 더 얻을 수 있습니다.

**미해결:** 기존 365일 × 하루100타격 엔딩 목표와 현재 약21만타격은 일치하지 않습니다. 이 변경은 자원 분리와 상대 성장속도 개편이며 최종 플레이 기간 확정이 아닙니다.

## 기존 저장 유지

v1–v4를 v5로 읽을 때 이전 캐릭터 레벨과 그 레벨 안에서의 XP 진행 비율을 새 곡선으로 변환합니다(정수 XP 내림). 기존 레벨/장비/목재/퀘스트/피로도는 유지하며 재접속으로 레벨업 회복이나 보상을 재지급하지 않습니다. 코인은 신규 재화로 0부터 시작하고 목재 환급/변환은 없습니다. 이미 지나간 고목 진입 XP는 소급 지급하지 않습니다.

성장 퀘스트는 고목10 / 캐릭터5 / 도끼15로 조정합니다. 완료된 과거 퀘스트는 유지됩니다. 보석·첫 기록 장착 보상은 기존 방식과 동일합니다.
