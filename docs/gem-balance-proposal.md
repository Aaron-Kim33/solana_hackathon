보석 하나는 같은 등급의 옵션 하나로 변환되며 세 종류 각각 1/3 확률입니다. 중복 획득과 같은 종류의 양쪽 슬롯 장착을 허용합니다. 아이템은 인벤토리에 추가되며 장착 중인 옵션을 자동 변경하지 않습니다. 보석 소비와 옵션 지급은 하나의 상태로 저장 성공 후 반영됩니다.

목재 100개 후 성장 목표 세 개를 모두 달성 → 하급 보석 1회 수령 → 하급 보석 사용 → 해당 보상 옵션 슬롯 1 장착까지 구현했습니다. 이미 달성한 레벨도 인정합니다. 슬롯 퀘스트 완료는 해제/강화/재시작 후 유지됩니다.

저장 v4는 v1/v2/v3을 유지하며 변환합니다. 예전 테스트 옵션은 기존 수치로 보존하고 별도 표기합니다. 상위 보석의 정식 획득처/가격/등급 확률과 유료 뽑기는 미구현입니다. 개발 모드에서만 각 등급을 2개까지 채우는 테스트 버튼이 있습니다. 난수 및 보상 권한은 현재 로컬 프로토타입이며 서버 검증/변조 방지는 없습니다. 실제 유료 보상에 그대로 사용하면 안 됩니다.

## 이전 비교 기록 (아래 10%p 제안은 13%p 확정으로 대체)

구현 완료: 첫 기록의 도끼 장착 공격력 +2. 최초 장착의 영구 +1과 별도이며, 도끼를 교체하면 +2만 제거됩니다. 같은 종류 옵션은 보유 수량만큼 두 슬롯에 중복 장착하고 합산합니다.

다음 퀘스트/보석은 아직 미구현: 목재 100개 후 성장 목표 3개(고목 10 / 캐릭터 15 / 도끼 15)를 모두 달성하면 하급 보석 1개, 사용 후 슬롯 1 장착 안내. 이미 달성한 레벨도 인정하는 방향을 제안합니다. 등급은 하급/중급/고급/최고급/전설이며 상위 수치는 미확정입니다.

계산 기준: 도끼 200, 캐릭터 200, 첫 기록의 도끼 장착 +2와 영구 +1, 슬롯 비어 있음. 평균 일반 피해 203.7, 치명타 확률 21.9%, 총 치명타 배율 304%. 기대 피해 = D × (1 + c × (m - 1)). 목재 내림이나 막타 초과 피해는 반영하지 않은 타격 피해 비교입니다.

| 옵션 | 기대 피해 증가 |
| --- | ---: |
| 피해 +1 | 1.446760 |
| 치명타 확률 +1%p | 4.155480 |
| 치명타 피해 +5%p | 2.230515 |

피해 +1과 정확히 맞추려면 확률 약 +0.348157%p 또는 치명타 피해 약 +3.243108%p가 필요합니다. 표시와 관리가 쉬운 근사안은 피해 +3 / 확률 +1%p / 치명타 피해 +10%p이며 기대 피해 증가는 4.340280 / 4.155480 / 4.461030입니다. 피해 +3 기준 약 -4.26% / +2.78% 오차입니다.

이 동등성은 위 만렙 기준에만 해당합니다. 초반에는 고정 피해가 더 강하고, 다른 옵션과의 조합으로 가치가 변합니다. 슬롯 두 개의 같은 옵션은 단순 합산되지만 서로 다른 옵션은 곱셈 효과도 발생합니다. 랜덤 보상 수치 및 확률은 사용자 확인 후 확정합니다. 현재 개발 옵션 수치는 변경하지 않았습니다.
