# 서버 숲 통합 1단계 — 2026-09-20

> 아래는 이전 단계의 역사 기록. 사용자 피드백으로 별도 서버 숲은 제거했다. 현재 검증 절차는 [main-server-qa.md](./main-server-qa.md)를 따른다.

## 현재 범위

메뉴의 **서버 숲 플레이 · 개발용**에서 전체 화면 서버 벌목에 진입한다. 기존 로컬 화면은 언마운트되어 해당 타이머와 입력이 중단되고, 돌아갈 때 기존 로컬 저장을 다시 읽는다. 서버 진행은 로컬 파일에 저장하거나 로컬 재화와 합치지 않는다. 로그인 세션은 앱 메모리에만 유지되므로 앱 재시작 후 다시 서명해야 한다.

지원: 로그인, 타격 배치, 서버 드롭 드래그 회수/만료, 목재·코인·캐릭터/고목 상태 표시, 고목 강화 및 다시 키우기, 자연 회복 확인, 미확인 요청 재전송.

아직 미지원: 서버 장비·퀘스트 화면, 자동 회복 조회, 영구 로그인, 운영 API, 랭킹/결제/에어드랍. 서버 숲은 release에서 노출하지 않는다. 전체 메인 게임의 서버 전환 완료로 간주하지 않는다.

## 안전 장치

- 입력 즉시 나무의 눌림/기울임 표시, 확정 데미지와 재화는 서버 응답 후 표시.
- 드래그 중 타격 금지. 회수 요청 처리 중 새 타격 금지.
- 전송 중, 큐 대기 중, 응답 미확인 상태, 드래그 중에는 모드 변경/로그아웃 금지.
- 미확인 요청은 같은 requestId로 재확인. 로컬 보상을 먼저 지급하지 않음.
- 백그라운드 전환 시 미전송 타격 취소; 이미 전송한 요청은 결과를 처리.
- 드래그 중 드롭이 회수/만료되어 제거되면 드래그 잠금 해제.
- 목재 부족/만렙이면 고목 강화 비활성화.

## 수동 Android QA — 실행 결과 아직 미확인

서버 시작: `node --experimental-strip-types server/start.mjs`
포트 연결: `adb -s emulator-5554 reverse tcp:8787 tcp:8787`
Metro에서 `r`로 다시 로드. 에뮬레이터 ID가 다르면 실제 연결된 ID 사용.

1. 로컬 목재/고목/장비 상태를 기록하고 메뉴에서 서버 숲 진입. 로그인 취소해도 로컬 복귀 가능.
2. 로그인 후 타격, 목재 드래그, 5초 만료 확인. 화면 스크롤과 드래그가 충돌하는지 확인.
3. 드래그 중 다른 손가락으로 나무를 눌러도 타격이 추가되지 않는지 확인.
4. 고목 처치 후 충분한 목재일 때 강화, 부족할 때 비활성화, 무료 다시 키우기 확인.
5. 응답 대기 중 앱 백그라운드→복귀. 미전송 타격이 나중에 자동 실행되지 않는지 확인.
6. 통신 끊김 후 미확인 요청 재확인. 중복 목재/XP가 지급되지 않는지 확인.
7. 로컬 숲 복귀 시 기존 진행 보존. 서버 숲 재진입 시 서버 진행 유지.
8. 한국어/영어, 작은 화면/큰 글꼴에서 잘림 및 스크롤 확인.

자동 검증: 테스트 120개 및 TypeScript 검사 통과. Android export는 JavaScript 번들 검사이지 독립 APK/실기기 검증이 아니다.
