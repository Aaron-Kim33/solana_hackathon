# Second forest equipment update

- Medium gems now yield +15 damage / +5 percentage points critical chance / +65 percentage points critical damage. Existing unused and equipped medium options use these values too.
- Other tiers are intentionally unchanged per request. This temporarily makes medium stronger than high (12/4/52); rebalance higher tiers before release. Do not represent current tiers as a monotonic power ladder.
- Tree level 101 permanently unlocks the Deepwood Axe, including existing saves already above 100. Unlock is derived from monotonic tree level; no repeated claims, currency charges or automatic equipment switch.
- Level 1 base rolls: 250 / 275 / 300, weighted 50/30/20. Each upgrade adds 1 to all three rolls, up to level 200. Permanent +1, slots and lumber mastery apply on top, then criticals as before.
- Strength is the new axe's only unique bonus; Pioneer keeps its own +10% hit XP bonus. Slots remain shared as in the existing system; axe levels remain independent.
- Korean/English inventory, comparison, forest icon and level-101 notification are included. The blue axe art is a code-drawn placeholder.
- No tree HP or boss balance changes in this update.
