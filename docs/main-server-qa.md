# 기존 게임 화면의 서버 연결 — 2026-09-20

별도 서버 숲 화면/메뉴는 제거했다. 기존 App의 나무, 데미지 표시, 드래그 목재, 캐릭터/도끼/고목 패널을 사용한다. 개발 메뉴에서 서버 저장을 연결하면 동일 UI의 데이터 원천만 서버로 바뀐다. 로컬 저장은 업로드하거나 덮어쓰지 않는다. 명시적 로그아웃 시 로컬 저장을 다시 읽는다. 세션 만료는 로컬 모드로 자동 전환하지 않고 재로그인을 요구한다.

## 연결 범위

- 서버: 벌목 배치, 회수, 만료, 고목 강화/다시 키우기, 도끼 강화/장착, 서버 시간에 따른 자연 회복.
- 즉시 클라이언트 피드백: 나무 반동. 재화/확정 데미지/드롭은 서버 응답 후.
- 첫 기록 연결: 서버 선행 조건·Devnet 거래 검증 → 첫 기록 보상 → 장착 → 목재 100개 퀘스트. 상세 확인은 `first-record-server-qa.md` 참조. 실제 지갑 수동 QA는 아직 미완료.
- 미연결: 이후 퀘스트 보상, 보석/특성, 자동줍기. 해당 변경은 안내 후 거절한다. 로컬 계산 결과를 서버에 저장하는 우회 API는 없다.
- API는 여전히 개발 PC loopback, release 비활성. 영구 세션/운영 배포/공식 랭킹 아님.

## 확인 방법

1. 서버에 신규 명령이 추가됐으므로 서버 터미널에서 Ctrl+C 후 `node --experimental-strip-types server/start.mjs` 재실행.
2. 필요하면 `adb -s emulator-5554 reverse tcp:8787 tcp:8787`; 실제 연결된 기기 ID 사용.
3. Metro `r`, 기존 메뉴 → **서버 저장 연결 · 지갑 서명**. 별도 게임 화면으로 이동하지 않아야 한다.
4. 기존 나무에서 탭, 기존 목재를 드래그, 서버 목재/XP 변경 확인. 회수 실패 시 목재가 성공한 것처럼 사라지지 않고 위치가 복원되어야 한다.
5. 도끼 강화 코인 차감 및 레벨 증가 확인. 장착 교체는 소유한 도끼만 가능하며 다른 도끼 강화 수치는 유지.
6. 미연결 기능은 안내되고 상태 불변이어야 한다. 첫 기록만 선행 조건 충족 후 사용자 승인으로 Devnet 거래를 요청한다.
7. 서버 끊김 → 메뉴의 미확인 요청 재확인. 처리 중 로그아웃 금지, 응답 유실 재전송에도 중복 지급 없음.
8. 로그아웃 → 이전 로컬 진행 유지. 재로그인 → 서버 진행 유지. 한국어/영어 확인.

자동 검사: 127개 회귀 테스트, TypeScript 통과. 입력 큐의 순서/만료/상한, 실제 서버와의 연타→회수→연타 처리, 개별 타격 결과와 재전송의 중복 지급 방지도 포함한다. UI 수동 테스트는 아직 사용자 확인 필요.

## 반응성 개선 확인

- 첫 타격의 고정 600ms 전송 대기를 제거했다. 이미 대기 중인 타격만 서버 시간 예산 내에서 묶는다. 네트워크 응답 시간은 여전히 필요하다.
- 처리 중 회수 입력도 큐에 보존한다. 최대 12개, 2초 이상 오래된 미전송 입력은 취소 안내한다. 백그라운드에서는 미전송 입력을 버리며, 이미 보낸 미확인 요청은 같은 ID로 재확인한다.
- 서버 컨트롤러의 250ms 주기 전체 화면 갱신을 제거했다. 목재 객체와 콜백을 유지하고 목재 컴포넌트를 메모화했다.
- 서버는 배치의 모든 타격 데미지/치명타를 반환한다. 화면에서는 최근 8개 데미지 표시로 제한한다.
- 재시작 후 빠른 연타 중 회수, 회수 종료 직후 연타, 메뉴 열기/닫기, 앱 백그라운드 복귀를 확인한다. 나무 반동은 즉시, 보상은 서버 확정 후여야 한다.
- 즉시 전송으로 작은 배치가 늘 수 있다. 기존의 4타격 배치 기준 75% 쓰기 절감 수치를 실제 플레이에 그대로 적용하면 안 된다.

아직 실기기 프레임 개선 수치는 측정하지 않았다. 변경 전 에뮬레이터 누적 gfxinfo는 601프레임 중 janky 342개였지만 시작/화면 전환을 포함하므로 순수 플레이 FPS로 해석하지 않는다. 같은 조건의 실기기 release 빌드 비교가 필요하다. 로컬 모드의 매 행동 동기 파일 저장 역시 남은 성능 점검 대상이다.
