# 성장 규칙 v2 · 2026-09-12

후속 업데이트: 첫 Devnet 기록 보상으로 기념 스킨을 받고 최초 장착하면 영구 피해 +1이 해금됩니다. 추가 피해는 슬롯 피해와 합산한 뒤 치명타를 적용합니다. 아래 성장 시뮬레이션에는 이 선택적 지갑 퀘스트 보너스가 포함되지 않았습니다. 저장 스키마는 보상/장착 이력을 담는 v3로 확장됐으며 v1/v2 진행도는 유지합니다.

## 확정하여 구현한 규칙

| 항목 | 공식 / 상한 |
| --- | --- |
| 피로도 | 성공한 타격마다 +1%p; 30분마다 −20%p; 캐릭터 레벨 상승 시 0 |
| 도끼 | Lv.1–200, Lv.L 일반 피해 L / L+1 / L+2, 확률 50 / 30 / 20% |
| 나무 | Lv.1–1000, HP = 200 + 100 × L |
| 외형 | Lv.1–50, 51–100, …, 951–1000의 20단계. 현재는 코드 기반 임시 색상/형태 |
| 캐릭터 | Lv.1–200; 회수 목재 1개 = XP 1 |
| 치명타 확률 | 2 + 0.1 × (캐릭터 L−1)%, 만렙 21.9% |
| 치명타 피해 | 일반 피해 × (105 + L−1) / 100, 만렙 총 304% |
| 기본 목재 | floor(최종 타격 피해 × 0.7); 나무 레벨 배수 없음 |
| 풍성한 수확 | 기본 목재 ≥1인 타격에서 독립적인 10% 확률로 나무 레벨만큼 추가 드랍 |

치명타는 피해를 소수 둘째 자리까지 보존합니다. Lv.1의 1 데미지 치명타는 1.05이고 목재는 0입니다. 마지막 타격은 남은 HP에 제한하지 않고 타격 데미지로 목재를 계산합니다. 일반 만렙 도끼는 목재 140 / 140 / 141개를 만듭니다. 만렙 캐릭터의 최대 기본 치명타는 202 × 3.04 = 614.08, 목재 429개입니다.

화면에는 개별 목재 수량만큼 객체를 생성하지 않고 한 타격의 기본+추가 목재를 +총수량 묶음 하나로 표시합니다. 추가 수확 묶음은 금색 별표로 구분합니다. 기본 목재가 0개이면 추가 수확도 없고 묶음도 만들지 않습니다. 각각 5초 뒤 만료하며 수집 중에만 벌목이 잠깁니다. 추가 목재도 회수해야 재화와 같은 양의 XP를 얻습니다. 치명타와 수확 판정은 독립이고, 막타에도 수확이 발동할 수 있습니다. 치명타는 추가 목재 자체를 배수 증가시키지 않습니다.

## 임시 수치 / 미완성 영역

- 기존 비용 유지: 도끼 강화 20 × 현재 레벨, 나무 강화 30 × 현재 레벨 목재.
- 기존 XP 곡선 확장: Lv.L 누적 필요 XP = 15 × L × (L−1). 다음 레벨까지 30 × L. Lv.200은 597,000 XP.
- 옵션 샘플: 피해 +2, 치명타 확률 +2%p, 치명타 피해 +10%p. 개발 모드에서만 각 종류를 2개까지 채워 지급하며 구입/드랍/희귀도는 미구현. inventory 배열의 각 항목은 소유한 1개이며 같은 종류 2개를 보유하면 양쪽 슬롯에 장착 가능. 기존 저장은 그대로 호환되며 장착 수량이 보유 수량을 초과한 저장은 거부합니다.
- 슬롯은 강화와 저장/재시작 이후에도 유지. 만렙에서도 옵션으로 기본 수치 이상 성장 가능.
- 개발용 휴식 −28%p 유지. 유료 50%/100% 회복은 아직 구현하지 않음.
- 서버 시간, 게임 검증, 조작 방지, 실결제는 별도 설계 필요. 피로도만으로 매크로를 막을 수는 없음.

## 365일 목표와 기본 공식의 차이

하루 100회 × 365일 = 36,500회. 하지만 모든 나무를 한 번씩 베는 데 필요한 총 HP는 **50,250,000**입니다.

처음부터 만렙 도끼/캐릭터를 지급하고 장비 옵션 없이 계산해도 평균 피해는 200.7 × (1 + 0.219 × 2.04) = **290.364732**. 성장 대기·막타 초과 피해를 무시한 기대 작업량은 약 **173,058회**입니다. 심지어 모든 타격이 최대 치명타 614.08이라고 해도 최소 **81,830회**가 필요합니다. 따라서 현재 기본 수치와 36,500회 엔딩은 양립하지 않습니다.

아래 3개 시드는 추가 수확 도입 전의 이전 진단 기록입니다. 현재 재현 명령은 문서 아래의 5개 시드 × 4개 조건 비교를 출력합니다.

조건: 신규 캐릭터, 목재 100% 회수, 살아 있는 나무에서는 가능한 도끼 강화를 우선, 쓰러지면 나무 강화를 우선, 부족하면 같은 나무 반복. 옵션 없음. 피로도 제한을 제거하여 순수 타격 작업량만 측정합니다. 자연 회복/레벨업으로 정해지는 실제 달력 기간을 예측한 결과가 아닙니다.

**다음 밸런싱 결정:** 확정된 기본 공식을 유지하려면 초반 퀘스트 보상/무료 스킬 및 후반 장비 성장으로 추가 피해를 설계해야 합니다. 36,500회에 50,250,000 HP를 처리하려면 전체 여정 평균 약 1,376.7 피해가 필요합니다. 이 수준을 유료 아이템에만 의존시키기보다는 무료 진행 기준부터 정한 후 유료 단축 범위를 결정하는 편이 좋습니다. 이번 구현에서는 수치를 임의로 바꾸어 365일 달성을 주장하지 않습니다.

## 저장 호환

v1 저장의 재화·XP·강화 레벨·언어·지갑 퀘스트·공개 거래 영수증·피로도 기준 시각을 유지합니다. 나무 잔여 HP는 새 최대 HP에 비례 변환하고 0 HP는 그대로 유지합니다. 과거에 기록하지 않았던 타격 횟수는 변환 이후부터 집계합니다. 새 옵션 슬롯은 비어 있습니다. 저장 파일을 삭제하거나 초기화하지 않습니다.

**피로도 주의:** 이 시뮬레이션은 실제 피로도 +1과 레벨업 초기화를 적용하고, 탈진하면 새 세션을 시작합니다. 자연 회복과 실제 시간 경과는 제외합니다. 따라서 세션 수는 날짜가 아닙니다. 전 조건에서 첫 탈진 전에 캐릭터 만렙에 도달했습니다. 빠짐없는 수집/즉시 강화 조건에서는 기본 방식도 약 7천 회, 새 방식도 약 6.5천 회 동안 레벨업 초기화가 이어집니다. 이는 기존 XP 곡선의 문제이지 추가 수확만의 문제는 아닙니다. 오히려 조기 만렙으로 회복 혜택도 일찍 끝나므로 새 방식의 후반 탈진 세션 수가 약간 늘 수 있습니다. 유료 피로도 회복 전에 XP 곡선 또는 회복 규칙을 별도로 합의해야 합니다.

**강화 비용 주의:** 나무 L→L+1의 평균 추가 이익은 발동 대상 타격당 0.1 목재입니다. 현재 비용 30L만을 그 증분으로 회수하려면 300L회의 발동 대상 타격이 필요합니다(목재 100% 회수, 다른 조건 동일). 예: Lv.100→101은 약 30,000회. 추가 수확이 존재한다고 모든 강화가 즉시 경제적으로 유리한 것은 아닙니다. 비용/완료 보상/진행 해금은 다음 밸런싱 대상입니다.

이번 반영은 10% 추가 수확, 안내와 연출, 회수 시 보상/XP, 테스트만 변경했습니다. XP·강화 비용·피로도 회복·저장 스키마는 변경하지 않았습니다.
