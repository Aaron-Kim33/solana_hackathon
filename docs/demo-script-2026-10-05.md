# Lumber Rush — 3분 촬영표와 영문 대본

제출용 실제 폰 영상. 최신 보안·주간 순위 배포/새 APK 확인 후 촬영한다.
기존 계정을 초기화하거나 개발 재화를 주입하지 않는다. 아래는 촬영 대본이며 촬영 완료 기록이 아니다.

## 촬영 전

- 새 APK를 기존 앱에 덮어 설치하고 서버 저장·음향·순위 창을 확인한다. 삭제/데이터 초기화 금지.
- 폰 화면 녹화를 사용한다. 방해 금지, 알림 미리보기 끄기, 음악은 내레이션보다 작게 설정한다.
- 영어 UI 권장. 도입은 실제 게임, 슬라이드/긴 로고 화면부터 시작하지 않는다.
- 실제 지갑 서명과 재접속은 별도 짧은 테이크로 촬영해도 되지만 편집 컷을 숨기지 않는다.
- 선행 진행이 필요한 공동숲/보스/농장은 화면에 `Progressed account`를 표시한다.
- 귀환 다람쥐는 실제 귀환 후 찍고 `Recorded after the expedition returned`로 다른 시점임을 표시한다.
- 지갑 시드·토큰·설정의 개인 정보·잔액 상세는 보여주지 않는다. 실제 거래 승인/수수료 지불은 사용자 선택이다.
- 두 번째 계정 영상이 없으면 다중 계정 실증·실제 다른 유저 수를 주장하지 않는다.

## 컷과 대본

### 0:00–0:10 — 바로 게임

화면: 개인 숲에서 실제 벌목. 짧은 제목 `Lumber Rush`만.

> This is Lumber Rush, a mobile forest game where your harvest helps grow a forest we share. I built it as a solo developer for Android and Solana Mobile.

### 0:10–0:40 — 모바일 손맛

화면: 홀딩 → 놓기 → 여러 목재 쓸어 트롤리에 싣기 → 트롤리 출발/보관함 도착 → 강화 하나.
목재가 화면에 있을 때 불필요한 패널을 열지 않는다.

> Hold the tree to chop. Dropped wood disappears after five seconds, so timing matters. Sweep several logs into the trolley, or drag them directly into storage. The trolley delivers its load before the resources reach your balance. Then use wood and coins to improve your tree and axe. Short tutorials introduce each action as it becomes available.

### 0:40–1:05 — 무료 지갑과 저장

화면: 실제 MWA 메시지 서명/로그인과 서버 저장 복구. 이미 로그인했다면 별도 로그인 테이크와 재실행을 명확한 컷으로 연결한다.
자막 `Free wallet message signature`.

> Mobile Wallet Adapter lets players sign in with a free wallet message. The server links that wallet to their game progress and restores it on return. Local practice stays separate. Normal growth rewards do not require SOL or an on-chain transaction.

### 1:05–1:50 — 핵심 차별점: 공동숲

화면: `Progressed account` → 공동숲 → 자재 퀘스트 보상 → 시설 기여 → 생명나무 반응 → 시설 창 탐험 보상 → 기여 순위.
레벨이 실제 오르지 않으면 레벨업 컷을 만들지 말고 내 기여/남은 목표 변화로 보여준다.

> Daily and weekly quests provide limited building materials. Players decide whether to contribute to the mine or the sapling path. Each facility needs both materials and enough contributing accounts to grow. Higher facility levels improve rewards for new squirrel expeditions. The life tree reflects that shared growth. Weekly contribution rankings show what each player has added, including your own place. This shared state lives on the game server.

### 1:50–2:15 — 재방문과 복원

화면: 실제 귀환 펫 수령 또는 출발/4시간 표시 → 농장 심기·물길 퍼즐 완료.
귀환 영상이 없으면 출발 장면만 보여주고 아래 대본의 brings back을 will bring back으로 바꾼다.

> A squirrel explores a facility for four hours and brings back a reward fixed at departure. Planting and a water-path puzzle let players restore saplings after harvesting. These give players a reason to return between short chopping sessions.

### 2:15–2:35 — 월드보스와 공동 보상

화면: 보스 실제 타격/피해 연출 → 피해 순위 → 공동 목표와 참여 조건.
이번 주 admin 계정이라 순위 제외라면 개발 결과를 경쟁 증거로 쓰지 않는다. 일반 서버 계정으로 촬영한다.

> The world boss gives each account up to one hundred attacks a week. Together, players unlock better community rewards. Everyone meeting the participation rule earns the same unlocked reward. Damage rankings show contribution, without adding rank-based prizes.

### 2:35–2:50 — 선택형 Mainnet

화면: 선택형 기념 기록 카드와 실제 수수료 안내까지만 보여줘도 된다. 실제 finalized 기록이 없으면 Explorer 성공 화면을 넣지 않는다.

> Players can optionally record a growth milestone as a public Mainnet Memo. They review the real network fee before signing. Cancelling never blocks gameplay. Ordinary chopping and community progression remain server-managed.

### 2:50–3:00 — 마무리

화면: 개인 숲/공동숲으로 복귀. 제목, 소스 저장소 주소만 짧게.

> Lumber Rush combines one-finger harvesting with shared weekly goals. The Android build and source are available for you to try. Thank you.

전체 게임 소리를 높여 말이 묻히지 않게 하고, 자막은 폰의 중요 버튼을 가리지 않는다.
